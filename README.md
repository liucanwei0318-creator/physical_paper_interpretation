# PhysicaAnnotate — 理论物理英文论文深度翻译与精准批注系统

**PhysicaAnnotate** 是一套面向理论物理与数学物理科研人员的全栈学术精读工作台。系统围绕**个人知识背景建模（K1–K4 四级掌握度）**与**防截断分节增量翻译引擎**构建，将英文预印本或期刊论文转化为包含严密数学推导还原、五类精准批注、伴读导师问答及联网文献核验的中文深度批注文稿。

---

## 核心功能特性

1. **K1–K4 个人知识背景建模（阶段 1）**
   - 支持录入已读教材（内置 Landau、Weinberg、Peskin、Sakurai、Wald、Polchinski 等经典理论物理教材章节目录解析）与前沿论文。
   - 自动将物理概念划分为 `K1`（已熟练掌握，自动抑制冗余解释）、`K2`（推测掌握）、`K3`（核心知识缺口，重点展开）与 `K4`（延伸背景知识）。
2. **多源论文导入与全局预分析（阶段 2）**
   - 支持 **arXiv ID / URL 自动抓取**（优先提取 arXiv e-print TeX 源码以完整保留原始 LaTeX 方程，回退至 ar5iv HTML 与 Atom API）、**PDF 原文解析**与**纯文本/LaTeX 粘贴**。
   - 在正式翻译前生成论文全局论证骨架、前置知识缺口评估与针对性补齐建议。
3. **防截断分节深度翻译与边译边读（阶段 3）**
   - 按论文自然章节（`\section` / 编号标题）智能切分长文，逐节调用模型生成中文学术译文与五类深度批注（概念定义、物理背景、理论解释、数学推导、铺垫过渡）。
   - **边译边存与断点续译**：每译完一节立即写入本地持久化快照，支持中途随时切换至阅读视图边译边读，页面刷新或网络中断后可一键从断点续译剩余章节。
   - **可拖拽双栏工作台与公式推导思维导图**：支持自由拖动调整主文稿与 AI 伴读导师栏宽度，并为关键方程生成结构化推导思维导图。
4. **专业术语统一表、词云与联网文献核验（阶段 4）**
   - 自动汇总全文「中文术语（English Term）」首次出现章节、词频权重词云，以及基于 arXiv / CrossRef / OpenLibrary 的引文真实性核验清单。
5. **多论文历史归档库与 Markdown + LaTeX 导出**
   - 内置多论文历史记录库，支持检索、一键切换历史精读文稿或直接导出纯中文学术 Markdown（含完整编号 LaTeX 公式与五步法公式推导卡片）。

## 运行环境要求

- **Node.js**：`>= 22.18.0`（生产环境 `npm start` 使用 `node server.ts` 直接运行，依赖 Node.js 22.18+ 原生 TypeScript 类型剥离支持及内置 `node:test` 测试运行器）。
- **环境变量**：在项目根目录创建 `.env`（参考 `.env.example`）：
  ```bash
  GEMINI_API_KEY="your_gemini_api_key"
  ```
  > **安全说明**：`GEMINI_API_KEY` 仅保存在服务端环境变量中，通过 Express 后端代理路由（`/api/*`）调用，绝不会打包进前端静态资源或暴露给客户端浏览器。

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 运行单元测试套件

本项目使用 Node.js 原生测试运行器（`node:test`），覆盖分节切分、防御式 Schema 清洗、知识图谱计算、arXiv/PDF 文本修复、推导思维导图及工作台持久化：

```bash
npm test
```

### 3. 启动本地开发服务

```bash
npm run dev
```

开发服务默认监听 `http://localhost:3000`（Express 服务端路由 + Vite 中间件同源运行）。

### 4. 类型检查与生产构建

```bash
# TypeScript 严格类型检查
npm run lint

# 构建前端静态资源与按需分包产物至 dist/
npm run build

# 启动生产环境服务器（自动托管 dist/ 静态产物与 /api/* 路由）
npm start
```
